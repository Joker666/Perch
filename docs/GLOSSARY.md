# Glossary

| Term | Means | Not |
| --- | --- | --- |
| Todo | One short thing to do, one line of text | task, item, entry, note |
| List | The panel view of todos that are not completed | inbox, today |
| Archive | The panel view of completed todos | done list, history, trash |
| Panel | The small floating window that shows the List or the Archive | widget, window, popup |
| Filler row | An empty row with a faint circle below the last todo. Click it to add a todo | placeholder, ghost row |
| Add | Start a new todo (filler row click, Return, or the global shortcut) | create, new |
| Complete | Mark a todo done. It leaves the List and goes to the Archive | check, finish, close |
| Restore | Move a completed todo back to the end of the List | uncomplete, reopen |
| Delete | Remove a todo for good (Command-Z can still undo it) | remove, trash |
| Clear Archive | Delete every completed todo | empty, purge |
| Theme | One of 8 color sets for the panel and Settings | background, skin, palette |
| Font | The type design for todos: System, Rounded, Serif, Monospaced | typeface |
| Font Size | The point size of todo text | text size |
| Radius | The corner radius of the panel, in px | corner, roundness |
| App Icon | One of 8 icons for the Dock, one per theme | logo |
| Sound | The short click when you complete a todo. On unless people turn it off | chime, ding |
| Global shortcut | The key combination that shows or hides Perch from any app. ⌃⌥Space unless people change it | hotkey, hot key |
| Show Perch / Hide Perch | Bring the panel up or put it away | open, toggle |
